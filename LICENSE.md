> **Status: UNLICENSED (all rights reserved by default).**
> No open-source license has been applied to this repository. Under copyright
> law, that means the default position is *all rights reserved*: the content
> and code in this repository may not be copied, modified, distributed, or
> reused without explicit permission from the copyright holder.

This repository is being prepared for **eventual public visibility**. Before
the repository is made public, the maintainers must decide on a license and
replace this document with the chosen license text. Until then, treat
everything in the repository as proprietary.

## Choosing a license (maintainer decision, not yet made)

Pick one of these families and record the decision in the pre-publication
checklist (`docs/pre-publication-checklist.md`):

| Intent                                                        | Suggested license                          |
| ------------------------------------------------------------- | ------------------------------------------ |
| Open source code + permissive reuse                            | MIT, Apache-2.0, BSD-3-Clause              |
| Code must stay open when modified                              | GPL-3.0, AGPL-3.0 (if served over a network) |
| Documentation / editorial content reuse                        | CC BY 4.0 or CC BY-SA 4.0                  |
| Mixed code + content with different terms                      | Split licenses per directory               |
| Keep all rights, publish for reading only                      | "All rights reserved" notice + README-only |

Whatever is chosen must be written into the actual `LICENSE`/`LICENSE.md`
file (a `docs/` mention is not a license grant).
