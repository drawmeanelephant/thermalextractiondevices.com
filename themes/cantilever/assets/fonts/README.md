# Cantilever webfonts

Cantilever self-hosts these WOFF2 webfonts so the archive does not depend on a
third-party font request at runtime. The files are the Latin and Latin-ext
subsets served by Google Fonts' CSS API, downloaded on 2026-08-03:

- **Crimson Pro** — variable 400–900 for editorial headings.
- **Plus Jakarta Sans** — variable 400–800 for interface and body copy.
- **IBM Plex Mono** — regular, medium, and semibold for code and archive metadata.

Each family directory includes its upstream `OFL.txt`. The font files are
distributed unchanged under the SIL Open Font License, Version 1.1.

Upstream sources:

- https://github.com/google/fonts/tree/main/ofl/crimsonpro
- https://github.com/google/fonts/tree/main/ofl/plusjakartasans
- https://github.com/google/fonts/tree/main/ofl/ibmplexmono
