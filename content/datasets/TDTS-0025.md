# Michigan CRA License Evidence

The normalized sample at `data/michigan-cra/licenses.json` contains three
source-connected adult-use processor licenses named in CRA recall releases.
Each license remains separate from its legal entity, DBA, brand, and premises.

| Field | Value |
| --- | --- |
| Records | 3 |
| Programs | Adult-use |
| License types | Processor |
| Registry coverage | Representative source-connected sample, not complete |
| Official lookup | [CRA licensing reports and verification](https://www.michigan.gov/cra/resources/cannabis-regulatory-agency-licensing-reports) |
| Retrieval date | 2026-08-09 |

CRA's separate Accela searches and periodic DOC/DOCX reports are preserved as
the authoritative acquisition route. No undocumented bulk endpoint was added.
