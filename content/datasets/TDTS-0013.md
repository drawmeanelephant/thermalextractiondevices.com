## Dataset Notes

Application detail rows (approved, pending, re-opened) for adult-use marijuana establishment licenses. The source file also carries EIN/TIN, business contact, and street-address fields; those columns are excluded from every generated page and never published. Only aggregate counts by license type and status are rendered.
