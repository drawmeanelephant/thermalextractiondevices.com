# Michigan CRA Recall and Advisory Sample

Three CRA public notices were normalized into `data/michigan-cra/recalls.json`.
The sample deliberately contains the different evidence shapes the CRA uses:
license-numbered producer recall, named products and strains, a banned-chemical
notice with the chemical withheld from the page text, and consumer instructions.

| Event type | Count |
| --- | ---: |
| Voluntary recall | 3 |
| Mandatory recall | 0 in this sample |
| Consumer advisory | 0 in this sample |
| Enforcement action | modeled as a source class, not counted in this sample |

The [CRA bulletin index](https://www.michigan.gov/cra/bulletins) remains the
authoritative discovery surface for the larger historical corpus.
