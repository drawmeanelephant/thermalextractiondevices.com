# Massachusetts Testing Requirements

Massachusetts requires licensed establishments to test cannabis and cannabis products through Commission-certified Independent Testing Laboratories. The applicable requirements are defined in the Commission's regulations: **935 CMR 500.160** (adult-use) and **105 CMR 725.100** (medical).

## Scope

- [x] Test results reported through Commission systems
- [x] Total Yeast and Mold and coliform limits enforced
- [x] Heavy-metal analytes (arsenic, cadmium, lead, mercury) required
- [x] Cannabinoid potency (THC/THCA) reported
- [x] Independent Testing Laboratory certification required
- [ ] Action-limit numeric values republished here (see note)

<Aside kind="tip">

This page intentionally does not restate numeric action limits. Limit values must be confirmed against the current regulation text and the Commission's published testing guidance before being republished; the importer never infers limits from single results.

</Aside>
