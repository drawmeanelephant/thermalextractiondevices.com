# Terpenes Reference Index

Catalog of volatile terpene compounds detected in cannabis laboratory analysis and botanical sources.

This collection provides rigorous physical property data (including pressure-referenced boiling points from NIST), chemical identity, sensory character, and evidence-classified biological research for thermal extraction analysis.

All satellite records in this collection follow the form identifier schema `terpenes/TTRP-XXXX`.
