## Technical Specifications

| Property | Specification |
| --- | --- |
| Manufacturer | [Smiss Technology Co., Ltd. (Flowermate)](../manufacturers/smiss.md) |
| Release | 2018 (research-corpus dating; part of the V5 series) [^2] |
| Heating Method | Hybrid conduction/convection ("Hybrid Heating System", per manufacturer); black ceramic heating chamber [^1] |
| Operation Mode | Session; haptic feedback when temperature is reached [^1] |
| Temperature Range | 104–446 °F (40–230 °C) [^1] |
| Temperature Control | Full temperature control; ~30-second heat-up (per manufacturer) [^1] |
| Battery | User-swappable 18650 lithium-ion, 2500 mAh; 10–12 sessions per charge; 5-minute session length [^1] |
| Charging | USB; 2–2.5 hour charge time [^1] |
| Output Voltage | 7.3 V (per manufacturer spec) [^1] |
| Dimensions | 122.78 × 50.2 × 23.2 mm [^1] |
| Weight | 155 g [^1] |
| Housing | Solid aluminum; borosilicate glass mouthpiece that stows into the device [^1] |
| Compatible Media | Dry botanicals; wax/concentrate via included pod [^1] |
| Includes | USB cable, brush, dabber, pouch, stainless screens, wax/concentrate pod, dry-herb capsule, loading cap [^1] |

## Warranty & Service

- Flowermate warranty terms vary by model (typically 1-year limited; see the [Smiss manufacturer record](../manufacturers/smiss.md) and current official warranty page) [^2].
- Removable 18650 supports user battery replacement.

## Cleaning & Maintenance Protocol

- Per manufacturer guidance: clean the borosilicate mouthpiece and ceramic chamber with the included brush; do not immerse the electronic housing. [^1]
