# TED-0001 Thermal Condenser Unit

The **TED-0001** is a dual-stage thermal condenser module designed for high-efficiency phase-change thermal extraction.

## System Overview

- **Primary Loop**: High-conductance copper micro-channel heat exchanger.
- **Operating Thermal Range**: -40°C to +220°C.
- **Max Vacuum Pressure**: 10^-3 Torr.
- **Control Interface**: Modbus RTU / CAN bus dual telemetry.
