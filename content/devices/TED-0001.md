# Arizer Solo III (TED-0001)

{{include includes/manufacturer-claim-note.md}}

## Technical Specifications

| Property | Specification |
| --- | --- |
| Manufacturer | [Arizer](../manufacturers/arizer.md) |
| Release / Model | Solo III, v2.0 [^1] |
| Heating Method | Hybrid: ~80 % convection / ~20 % conduction (Arizer "Instant Heating Ceramic Convection" per manufacturer) [^1] |
| Operation Mode | Session Mode and On Demand Mode [^1] |
| Temperature Range | 50 °C – 220 °C set-point; quick-select heat levels up to 220 °C (180/190/200/210/220 °C) [^1][^2] |
| Temperature Control | Digital color display; 1 °C and 10 °C increments; programmable presets |
| Chamber / Load | Glass Aroma Tube ("Glass Pod") system; XL tubes provide double the capacity of the standard Air/Solo tubes (per manufacturer). A gram capacity is not stated officially [^1] |
| Vapor Path Contact | Borosilicate glass aroma tubes; ceramic oven. "Isolated air path" is a marketing phrase; structural isolation is not independently verified here [^3] |
| Power Source | Internal lithium-ion battery (not user-replaceable); ~3 hours of Session Mode use or 100+ on-demand draws per charge (per manufacturer) [^1][^2] |
| Charging | USB-C (5 V / 3 A) with USB-C Power Delivery; "use while charging" supported [^1] |
| Heat-Up Time | ≈5–15 seconds (per manufacturer) [^1] |
| Compatible Media | Dry botanicals (raw plant material) |

## Warranty & Service

- 2-year limited warranty on electronics; lifetime warranty on the heating element; battery covered for 1 year; glass components excluded (see [Arizer manufacturer record](../manufacturers/arizer.md)) [^4].

## Cleaning & Maintenance Protocol

- Remove the glass aroma tube and soak the glass components in isopropyl alcohol, rinse with warm water, and dry fully before reuse [^2].
- Do not immerse the main unit body that contains electronics.
