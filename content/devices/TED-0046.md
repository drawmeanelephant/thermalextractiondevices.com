# FLYTLAB CTRL 2.0 (TED-0046)

{{include includes/manufacturer-claim-note.md}}

## Technical Specifications

| Property | Specification |
| --- | --- |
| Manufacturer | [FLYTLAB Ltd.](../manufacturers/flytlab.md) |
| Release | Current flagship; earlier CTRL units documented from 2020 customer reviews; CTRL 2.0 listed as the current model [^1] |
| Heating Method | Conduction via the attached 510 cartridge atomizer (device supplies regulated voltage) [^1] |
| Operation Mode | Inhale-activated (draw-activated) |
| Voltage Settings | 4 presets — 2.6 V (blue), 3.0 V (yellow), 3.4 V (purple), 3.8 V (green, default) [^1] |
| Pre-Heat | Pre-heat function triggered by 2 quick puffs within 3 seconds [^1] |
| Cartridge Compatibility | Universal 510-thread oil cartridges up to 11 mm diameter; ½-gram and full-gram cartridges with top and bottom airflow [^1] |
| Chamber | Concealed, spring-loaded enclosure that fully covers the cartridge [^1] |
| Power Source | Internal lithium-ion battery; USB-C fast charging with a manufacturer-stated ~40-minute charge time [^1] |
| Charge / Use | Usable while charging (per customer documentation) [^1] |
| Compatible Media | Pre-filled 510 oil cartridges (cannabis oils) |
| Design Origin | "Designed in the USA" (per manufacturer) [^1] |

## Warranty & Service

- 1-year limited warranty (per manufacturer warranty page); batteries excluded from normal degradation [^2].
- No published firmware update process; battery is non-user-replaceable (per manufacturer FAQ) [^2].

## Usage Notes

- Voltage presets are the only temperature control; the manufacturer does not publish a cartridge temperature setpoint, and voltage is a poor proxy for coil temperature in general (see [Vaporizer Heating Architectures guide](../guides/TGDE-0001.md)).
- The concealed chamber is marketed for discretion and cartridge protection; the enclosure does not alter the cartridge's chemistry.
