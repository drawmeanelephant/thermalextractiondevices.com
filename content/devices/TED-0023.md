# VapeXhale Cloud (Gen 1) (TED-0023)

## Technical Specifications

| Property | Specification |
| --- | --- |
| Manufacturer | [VapeXhale, Inc. (Hanu Labs)](../manufacturers/TMFR-0013.md) |
| Family | Cloud (desktop convection) |
| Generation | 1 |
| Release Period | February 2012 (limited release) – discontinued c. 2014 [^1] |
| Heating Method | True convection via the PerpetuHeat™ System (PHS): ceramic heating element wrapped around the external glass air path [^1] |
| Heat-Up Time | ~6–15 minutes [^1] |
| Temperature Control | Analog radial dial with multiple hashmarks (clock-position reference) [^1] |
| Temperature Range | ~200–500 °F (93–260 °C); 7:00 ≈ 200 °F, 12:00 ≈ 350 °F, 5:00 ≈ 500 °F [^1] |

| Chamber | Stainless steel EZ Load Bowl (ELB) with mesh screens; optional borosilicate glass VapeXNail for concentrates [^1] |
| Housing | Aluminum [^1] |
| Official Manual | Printed manual included; video instructions on the manufacturer channel [^1] |
| Warranty | 1-year manufacturing defects (per contemporary review) [^1] |
| Compatible Media | Dry botanical flower; concentrates/extracts via VapeXNail; essential oils [^1] |

## Revision Notes

- **Cloud+ (Gen 1.5, ~2013)**: interim revision moving the air-flow restriction from the top of the Bamboo (near the joint) to the bottom intake; otherwise identical housing and heater; backwards compatible with Gen 1 accessories [^1].
- Superseded by the [Cloud EVO](../devices/TED-0024.md) (May 2013) [^1].
- Replacement parts for the Cloud were reported as unavailable by 2016 [^1].
