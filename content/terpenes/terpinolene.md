# Terpinolene

## Identity

| Property | Value |
| --- | --- |
| Preferred name | Terpinolene |
| CAS number | 586-62-9 |
| Chemical family | Monocyclic Monoterpene |
| Molecular formula | C10H16 |

## Aroma and sensory character

Complex scent carrying herbal, citrus, pine, and floral undertones.

## Occurrence outside cannabis

- Apples (*Malus domestica*)
- Cumin (*Cuminum cyminum*)
- Tea tree (*Melaleuca alternifolia*)
- Sage (*Salvia officinalis*)

| Property | Value |
| --- | --- |
| Standard boiling point | 185 °C |
| Reference pressure | 101.325 kPa |
