# D-Limonene

## Identity

| Property | Value |
| --- | --- |
| Preferred name | D-Limonene |
| CAS number | 5989-27-5 |
| Chemical family | Cyclic Monoterpene |
| Molecular formula | C10H16 |

## Aroma and sensory character

Bright citrus, lemon, orange peel, and fresh terpene notes.

## Occurrence outside cannabis

- Orange peel (*Citrus sinensis*)
- Lemon rind (*Citrus limon*)
- Grapefruit (*Citrus paradisi*)
- Juniper (*Juniperus communis*)

## Physical properties

| Property | Value |
| --- | --- |
| Standard boiling point | 176 °C |
| Reference pressure | 101.325 kPa |
| Data source | NIST Chemistry WebBook |

## Thermal-extraction context

> Temperature note: The listed boiling point is a reference property measured under stated conditions. It is not a dosage recommendation or a guarantee that a vaporizer set to that temperature will selectively extract this compound.

Pure limonene liquid exerts significant vapor pressure well below 176 °C.

## Reported biological activity

### Human evidence
Early clinical and human trial data suggest potential mood-modulating and anxiolytic sensory response.

### Animal or laboratory evidence
In vitro and animal models demonstrate gastroprotective, antioxidant, and anti-inflammatory properties.

### Traditional or anecdotal claims
Commonly associated with uplifting citrus aromatherapy traditions.
