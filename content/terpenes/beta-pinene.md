# β-Pinene

## Identity

| Property | Value |
| --- | --- |
| Preferred name | β-Pinene |
| CAS number | 127-91-3 |
| Chemical family | Bicyclic Monoterpene |
| Molecular formula | C10H16 |

## Aroma and sensory character

Woody, pine-like, green, slightly spicy note.

## Occurrence outside cannabis

- Pine (*Pinus* species)
- Basil (*Ocimum basilicum*)
- Parsley (*Petroselinum crispum*)

## Physical properties

| Property | Value |
| --- | --- |
| Standard boiling point | 166 °C (Antoine estimate; not explicitly listed by NIST) [^1] |
| Reference pressure | 101.325 kPa |
| Data source | Secondary literature; NIST WebBook (CAS 127-91-3) lists no explicit boiling point |
