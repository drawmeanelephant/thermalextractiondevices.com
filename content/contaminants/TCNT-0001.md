# Pyrethrins

## Classification

| Field | Value |
| --- | --- |
| Contaminant class | Residual pesticide / plant growth regulator |
| Testing category | Required under the DCC mandatory testing panel |

## Description

Natural botanical insecticide compounds; subject to DCC residual-pesticide testing and Category II contamination action limits.

## Consumer Action

Do not consume products that test above action limits; return or dispose per recall notice.

## Regulatory Context

Contaminants in this class are tested under California's mandatory cannabis
testing requirements (see [Testing Requirements](../requirements/TREQ-0001.md)).
Action limits are set in the DCC regulatory text (Title 4, Division 42) and must
be read from the current regulation.
