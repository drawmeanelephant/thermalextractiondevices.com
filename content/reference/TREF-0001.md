# Physical Property Data Standards (TREF-0001)

Defines how the archive reports chemical physical properties, especially boiling points, so that values are reproducible and their confidence is explicit.

## Boiling points are reported with their measurement pressure

A boiling point is undefined without its pressure. Every terpene record in this archive reports the reference pressure alongside the value:

| Label | Meaning |
| --- | --- |
| **Standard (atmospheric) boiling point** | Boiling point at 101.325 kPa (760 mmHg) |
| **Reduced-pressure boiling point** | Boiling point at a stated lower pressure (e.g., 0.667 kPa / 5 mmHg) |
| **Pressure not given** | Used only where the reported value's pressure is unknown; stated explicitly |

A boiling point is a property of the pure compound and is **not a device setting** and **not an "activation temperature"** for a vaporizer. See the [boiling point vs device setting note](../includes/boiling-point-vs-device-note.md).

## Source hierarchy

The archive orders physical-property sources by confidence:

1. **Primary measurement** (e.g., NIST Chemistry WebBook, SRD 69) — preferred.
2. **Peer-reviewed or authoritative reference** with a stated method.
3. **Secondary literature** — reproduced from a compilation; verified where possible.
4. **Estimated / predicted** — computed values, never implied to be measured.

Where a value could only be sourced below the primary tier, the terpene record says so explicitly (e.g., "unconfirmed by NIST", "Antoine estimate", or "predicted"), rather than presenting it as a measured fact. Examples in this archive can be found across the [Terpenes collection](../terpenes.md).

## Relationship to evidence classification

Physical property confidence (this page) is distinct from biological-claim evidence class, which is governed by the [Evidence Labels and Claim Grammar](evidence-labels-and-claim-grammar.md) standard. A high-confidence boiling point does not license a clinical claim, and vice versa.
